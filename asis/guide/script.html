    • loop : false // 슬라이드 반복 안됨
    • space : '20' // 슬라이드 간 간격
    • perView : '1' // 한번에 보이는 슬라이드 수
    • autoplay : false // 자동 슬라이드 안됨
    • autoplaySpeed : '5000' // 자동 슬라이드 시간 (5초)
    • autoHeight : false // 슬라이드 높이값 고정
    • allowTouchMove : true // false시에 버튼으로만 슬라이드 조작이 가능
    • center : true // 슬라이드 가운데 정렬
    • fadeEffect : false // true시 fade in opt 효과
    • dir : 'horizontal' | 'vertical' // 슬라이드 방향 기본값은 'horizontal' 설정되어 있음


slide 모션컨트롤 function tweenFN(opts = {})

    • tweenFN함수는 슬라이드 내 모션이 들어갈 경우 슬라이드별 모션을 주기 위한 스크립트 입니다.
    • tweenFN함수는 전역변수 slideTween의 변수를 참조합니다.
    • tweenFN가 실행되면 슬라이드 수 많큼 slideTween['tween_{슬라이드 변수:slideObj.slideEl}_현 슬라이드의 리얼인덱스']로 배열을 형성합니다.
    • 위 배열로 각각의 애니메이션을 할당합니다.

    사용 예시

slide 모션컨트롤 function scrollMotionFn(opts = {})

    • scrollMotionFn함수는 슬라이드 내 모션이 들어가고 스크롤에 따라 해당 모션을 컨트롤 해야 할 경우 사용합니다.
    • scrollMotionFn함수는 전역변수 slideTween, slideScene를 참조합니다.
    • scrollMotionFn이 실행되면 슬라이드 수 많큼 slideTween과slideScene에 다음과 같은 규칙으로 배열을 형성합니다.
      slideTween['tween_{슬라이드 변수:slideObj.slideEl}_현 슬라이드의 리얼인덱스']
      slideScene['scene_{슬라이드 변수:slideObj.slideEl}_현 슬라이드의 리얼인덱스']
    • 위 배열로 각각의 애니메이션을 할당합니다.

mableUI.paramsFn(opts={})

    • 파라미터 관련 함수로 url?key=value 값을 전역변수 params에 객체로 리턴 합니다.
    • 다른 함수에서 파라미터 값으로 전달 할때
      ex)mableUI.selectTab 함수에서 파라미터 값 url?category=1을 사용하고자 할때
      mableUI.selectTab 함수에서 매개변수 paramID에 파라미터 함수를 호출 후 {paramID = paramsFn()}
      함수 내 paramID.category으로 파라미터 값 할당 가능
      paramID.category = 1
    • 파라미터 값은 자동으로 숫자일 경우 숫자로 문자일 경우 문자로 전역변수 params에 객체 형태로 할당됩니다.
      https:url.com?a=1&b=커피&c=10000
      params = {a:1,b:'커피',c:10000 }
    • 파라미터 값 사용 예시
      https://dtong.kbsec.com/mable/event/Event_0043.html?abcde=10000
      위 URL에서 파라미터 abcde로 사용할경우
      const paramID = mableUI.paramsFn();
      const paramValue = paramID.abcde;
      출력:
      paramValue = 10000;
    • a href 에 파라미터 값 할당 예시
      파라미터가 포함됨 URL로 접근시 a태그에 data-param-link 추가해 기존 href 링크 뒤에 파라미터 추가
      원본소스
      <a href="/mable/asset/Mable_03_0368.html" data-param-link></a>
      접근 URL
      https://dtong.kbsec.com/mable/asset/Mable_03_0368.html?lms=y&d
      접근 URL 뒤 파라미터값 스크립트 적용시
      <a href="/mable/asset/Mable_03_0368.html?lms=y&d" data-param-link></a>

      위와 같이 링크값을 파라미터 값과 동일하게 맞추는 이유는
      linkToFn의 각 매체별 링크값을 분기처리 하기 위함임

기타 함수 정의

  • 기타 함수는 mableUI에 추가되지 않은 나머지 선언식 함수입니다.
  • 기타 함수는 반드시 function 함수명(opts={}){ 함수내용 } 으로 기존 함수 선언식으로 정의 합니다.
  • const func = function(){}; 방식은 절대 금지합니다.

linkToFn(opts={})

  • onclick="linkToFn({webHtml:tongOpt.baseUrl+'/mable/asset/Mable_03_0194.html', openpopup:tongOpt.baseUrl+'/mable/asset/Mable_03_0194.html', popupTitle:'중개형 ISA 알아보기'});"
    • 모바일웹 화면과 마블 화면을 한 화면으로 같이 사용 할 경우 각 매체별 링크 값으로 분기 처리하는 함수
    • tongOpt 객체를 통해 모바일웹 화면과 변수값을 통신함
      tongCall : true, // 통체크
      mwebUrl : '', // 모웹 URL 체크
      baseUrl : '', // tong URL 체크
      isWeb : false, // 마블인지 모웹인지 체크
      height : '', // iframe 높이값
      scrollTop : false, // 모웹용 true일때 스크롤 최상단으로 이동
      fn : null, // 모웹용 callback함수
      lms : false, // lms용 applink
      linkcd = false, // linkcd 경로 설정
      KBbank = false, // KB 스타뱅킹
      KBpay = false, // KBpay
    • tongOpt.baseUrl과 tongOpt.mwebUrl은 자동으로 https URL 체크해서 url을 loc,dm,m 분기처리해서 자동으로 적용해줌

    기본값

    • 모웹용
      • webHtml = false, // 통URL 또는 htmlURl, ex) webHtml:tongOpt.baseUrl+'/mable/asset/Mable_03_0194.html
      • goMable = false, // 모웹용 goMable, ex) goMable:'4105'
      • appLink = false, // 한 화면에 goMable 2개 이상일 경우 appLink로 사용, ex) appLink:'4105'
      • goLink = false, // 모웹용 /go.able?linkcd=메뉴아이디, ex) goLink:'s010500010000'
      • youtube = false, // 모웹용 유튜브 링크, ex) youtube:'VfJ6iL3GtqU'
      • scrollTop = false, // 모웹용 true일때 스크롤 최상단으로 이동, ex) scrollTop:true
      • fn = null, // 모웹용 callback함수, ex)
    • 마블용
      • openpopup = false, // 마블용 풀팝업, ex) openpopup:tongOpt.baseUrl+'/mable/asset/Mable_03_0194.html'
      • popupTitle = '', // 마블용 풀팝업 타이틀 openpopup 과 겨의 세트로 사용됨, ex) popupTitle:'중개형 ISA 알아보기'
      • openscreen = false, // 마블용 화면번호 이동, ex) openscreen:'4105'
      • triggerEvent = false, // 마블용 triggerevent 호출, ex) triggerEvent:'&700002&'
      • openpopupID = false, // 마블용 바텀시트용 또는 kbsec://gmts?openpopup=화면아이디 호출, ex) openpopupID:'IS5700BT'
    • 기타 (LMS 및 외부링크)
      • lms : URL파라미터에 ?lms가 붙을 경우 lms 링크(app.kbsec.com)를 호출함 ex) lms:2288
      • linkcd : URL파라미터에 ?linkcd가 붙을 경우 자율주행용 전용 링크를 호출함 ex) linkcd:b040101
      • KBbank : URL파라미터에 ?bank가 붙을 경우 KB국민은행 전용 링크를 호출함 ex) KBbank:b020306
      • KBpay : URL파라미터에 ?pay가 붙을 경우 KBPay 전용 링크를 호출함 ex) KBpay:c020306
    • 기타 링크를 추가할 경우 URL파라미터를 설정하고 해당 부분에 업데이트 해주세요.

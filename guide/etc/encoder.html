와이드 SVG 작업방식
  1. 피그마에서 아이콘 우클릭, Copy as SVG, 업무망으로 가져오기
  2. SVG textarea영역에 붙여넣기, 해당 svg 최상위 width, height 속성 삭제

    예) <svg width="48px" height="48px" viewBox="0 0 48 48"> => <svg viewBox="0 0 48 48">

  3. _mixin.scss 내 아이콘 추가 아이콘명 : Ecoded textarea영역 복붙
  4. 색상들어가는 부분 변수명으로 변경
    %23 뒤 헥사코드 => 변수명 (themes.scss에서 색상코드 참고)

    예) %2363636d => %23#{$icon_type01}

Font Size

  • 화면 뷰포트 너비(Viewport Width) 기준으로 기준 font-size가 변경됩니다.
  • 사이즈의 기본단위는 rem 단위를 기본으로 하며, 이는 최상위 요소(html)에 설정된 font-size를 기준으로 산출합니다.
  • 뷰포트 너비 (Viewport Width) 319px 이하 (초소형 디바이스 (Fold 등)) 기준 font-size : 12px
  • 뷰포트 너비 (Viewport Width) 320px~359px 까지 (소형 모바일 (iPhone SE 등)) 기준 font-size : 14px
  • 뷰포트 너비 (Viewport Width) 360px~413px 까지 (표준 모바일 (Android / iPhone)) 기준 font-size : 16px
  • 뷰포트 너비 (Viewport Width) 414px 이상 (대화면 모바일 (Pro Max / Plus 등)) 기준 font-size : 18px
  • 피그마 540으로 작업 시 사이즈 계산은 계산할 값 X 2 / 3 입니다. 예) 디자인상 24px : 24x2/3=16px (1rem)
  • 1Depth 타이틀

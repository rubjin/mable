금액 표기

기본 표기

  • 1,000,000
  • 세자리 단위로 ‘,’ 표시하며 마지막에 ’원’과 같은 단위는 표시하지 않음
  • 조회성 화면의 경우 해당 표기정책으로 적용

단위 표기

  • 1,000,000원
  • 매수/매도/이체 등 업무 프로세스 수행 중 금액을 표시해야 하는 경우 또는 같은 영역에 여러 단위를 함께 표기해야 하는 경우에 한하여 마지막에 단위를 표기함. (예 : 1,000좌/1,000,000원)
  • 조회성 화면의 경우 해당 표기정책으로 적용

손익률 표기

  • 9.12% (상승 : class="upTxt")
  • -8.24% (하락 : class="dwTxt")
  • 8.24% (보합 : class="tnTxt")

손익금액 표기

  • 10,000,000 (상승 : class="upTxt")
  • -10,000,000 (하락 : class="dwTxt")

해외통화 표기

  • 1,000.00 USD (통화 코드와 함께 표기하는 경우)
  • $1,000.00 (통화 약호와 함께 표기하는 경우)

테이블 내 단위 표기

  • %, 배, 회 등의 단위는 테이블 바디에서만 표기하고 테이블 헤더에는 표기하지 않는 것을 원칙으로 한다.
테이블 타이틀
전체 현재가 ROA ROE
피엔텔 8,888 88,888 88,888
에이피티씨 8,888 88,888 88,888
  • 한 테이블 안에 여러 단위가 혼재되어 있는 경우 우측에 단위를 표기한다.
테이블 타이틀
구분 2019/03 2019/04 2019/05
단기순이익(억원) 8,888 88,888 88,888
EPS(원) 8,888 88,888 88,888
  • 상승일 경우 ‘▲ 1,000’, 하락일 경우 ‘▼ 1,000’으로 표기한다.

계좌 표기

내 계좌 표기

  • 계좌종류 + 계좌번호
  • 일반적인 계좌표기 방식
  • 계좌종류 + 계좌번호 + 계좌별명
  • 계좌 선택을 위한 바텀시트/팝업인 경우 계좌 별명을 함께 표기
  • 계좌별명을 지정하지 않은 경우에는 소유주명으로 대체

이체 시 계좌 표기

  • 계좌종류 + 계좌번호 + 소유주명
  • 이체 진행 과정 중 계좌표기 방식
